# 电脑体检助手 (PC Health Check)

一个用 PowerShell 写的 Windows 电脑体检脚本。双击运行,一键检查系统信息、处理器、内存、磁盘空间、硬盘类型、防火墙和病毒防护状态,并生成一份中文报告。

不需要安装 Python、Java 或其他环境,Windows 自带的 PowerShell 就能跑。

## 为什么做这个

在 IT 部实习时,经常要帮同事确认电脑的配置和运行状态,每次都要把同样的几项手动查一遍。于是写了这个脚本,把这件事变成一键完成,结果还能直接存成报告发给对方。

## 功能

| 检查项 | 检查内容 | 触发提示的条件 |
|---|---|---|
| 系统信息 | 计算机名、当前用户、操作系统版本、系统架构、已运行时长 | - |
| 处理器 | 型号、核心数与线程数、当前负载 | 负载达到 85% |
| 内存 | 总容量、可用容量、使用率 | 使用率达到 85% |
| 磁盘空间 | 每个分区的总容量、可用容量、使用率 | 使用率达到 85%,或可用空间低于 20 GB |
| 硬盘类型 | 固态硬盘还是机械硬盘 | 没有检测到固态硬盘 |
| 安全状态 | 防火墙三个配置文件是否开启、病毒防护实时保护是否开启、病毒库是否过期 | 防火墙未全开、实时保护关闭、病毒库超过 7 天未更新 |
| 系统状态 | 是否有等待重启才能生效的更新 | 存在待重启的更新 |

最后会给出一个总结论:要么"一切正常",要么列出需要处理的问题。

## 快速开始

### 方式一:双击运行

下载整个项目,双击 `run.bat`。脚本会自动执行,结束后停留在窗口里,方便你看结果。

### 方式二:在 PowerShell 里运行

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\pc-health-check.ps1
```

### 方式三:在已经打开的 PowerShell 窗口里调用

```powershell
.\pc-health-check.ps1
```

如果提示"禁止运行脚本",用前两种方式即可,或者临时放开一次:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

这条命令只对当前窗口生效,关掉窗口就恢复,不会改动系统设置。

## 参数

| 参数 | 说明 |
|---|---|
| `-OutputPath <路径>` | 指定报告保存位置,默认为 `reports\体检报告_日期时间.txt` |
| `-Json` | 保存文本报告的同时,再导出一份 JSON |
| `-NoFile` | 只在屏幕上显示,不保存文件 |

例如,输出 JSON 方便其他程序读取:

```powershell
.\pc-health-check.ps1 -Json -OutputPath .\reports\check.json
```

## 实现说明

读取信息时按"越少依赖越好"的顺序选择方案:

1. **注册表和 .NET 接口优先** —— 操作系统版本、处理器型号、磁盘容量这类信息直接从注册表和 `System.IO.DriveInfo` 读取,普通用户权限就能拿到。
2. **Win32 API 补充** —— 内存容量和使用率通过 `GlobalMemoryStatusEx` 获取,运行时长通过 `GetTickCount64` 获取。这两个接口不需要管理员权限,比 WMI 更稳。
3. **WMI 兜底** —— 处理器负载、硬盘介质类型这类信息只有 WMI 提供,读不到时脚本会跳过并给出提示,不会中断。

也就是说,在普通用户权限、甚至部分受限的环境下,脚本依然能输出大部分结果。

## 常见问题

**提示"无法读取硬盘型号"或"无法读取防火墙状态"**

这两项依赖系统管理接口,普通权限下有时会被拒绝。用管理员身份打开 PowerShell 再运行一次即可:

```
右键"开始"菜单 → 终端(管理员) / Windows PowerShell(管理员)
```

**提示"无法读取状态(可能装了第三方杀毒软件)"**

说明系统里装的不是 Windows 自带的 Defender,脚本读不到它的状态。这是正常的,不是脚本出错。

**报告会不会泄露信息?**

报告只包含本机的硬件和系统状态,不联网、不上传任何内容。所有检查都在本地完成。
